# Stitch lettering fonts

`stitch-fonts.json` holds single-stroke glyph outlines used to draw embroidery-style
lettering in the design studio. They were extracted from the SVG fonts shipped in
[hersheytext](https://github.com/techninja/hersheytextjs) 2.0.0 (MIT).

| Key | Font | Credit |
| --- | --- | --- |
| `rounded` | EMS Readability (Rounded) | EMS Readability by Sheldon B. Michaels (SVG conversion by Windell H. Oskay), a derivative of Source Sans Pro-Light by Paul D. Hunt, Adobe |
| `hand` | EMS Elfin (Handwritten) | EMS Elfin by Sheldon B. Michaels (SVG conversion by Windell H. Oskay), a derivative of Mountains of Christmas by Crystal Kluge, Tart Workshop |
| `script` | EMS Allure (Script) | EMS Allure by Sheldon B. Michaels (SVG conversion by Windell H. Oskay), a derivative of Allura by Rob Leuschke, TypeSETit |
| `typewriter` | EMS Nixish (Typewriter) | EMS Nixish by Sheldon B. Michaels (SVG conversion by Windell H. Oskay), a derivative of Nixie One by Jovanny Lemonad |

All four are licensed under the SIL Open Font License 1.1; see `OFL.txt`.
